The four ideas the rest hangs on

01

Build it by hand

Every abstraction is written from scratch once — tokenizer, attention, optimizer — before a library is allowed to hide it.

→02

Attention is the engine

One operation explains transformers, multimodal models and most of what agents can do.

→03

The agent loop

Model, tools, memory, control flow. Four parts, and every agent framework is a wrapper around them.

→04

Shipping is the exam

Serving, cost, observability and safety are where AI projects actually fail.
